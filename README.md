# Product Preview Card Component

This is a clean, responsive product preview card built as a front-end coding challenge. The goal was to practice building a professional layout that adapts perfectly to different screen sizes.

## 🚀 Features
* **Mobile-First Approach:** Optimized for smaller screens before scaling up to desktop.
* **Responsive Design:** Seamlessly transitions between mobile and desktop layouts.
* **Clean UI:** Implemented professional typography and spacing using modern CSS.
* **Interactive States:** Includes hover and focus states for the primary action button.

## 🛠️ Built With
* **Semantic HTML5** - For accessible and structured content.
* **CSS3 (Flexbox/Grid)** - For a robust and responsive layout.
* **Google Fonts** - Using 'Montserrat' and 'Fraunces' for an elegant look.
